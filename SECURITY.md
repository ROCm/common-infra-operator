# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in this project, **do NOT report it publicly via a GitHub issue**.

Report the issue through the [AMD Product Security website](https://www.amd.com/en/resources/product-security.html).

You may also use GitHub's [private vulnerability reporting](https://github.com/ROCm/common-infra-operator/security/advisories/new) feature to report directly to the maintainers.

## Supported versions

Security fixes are applied to the latest release on the `main` branch. Older release branches receive fixes at maintainer discretion.

## Response timeline

We aim to acknowledge reported vulnerabilities within 5 business days and provide an initial assessment within 10 business days.
